# Code areas

Each part lives in its own folder; read only the one you work on.

| Folder | What | Entry |
|---|---|---|
| `whiteboard/` | The whiteboard app, the home page `/` (tldraw; `/whiteboard` redirects there): Excalidraw's layout (toolbar, main menu with Clear page, zoom + undo/redo bottom left), shortcuts, first-visit defaults, the outline while dragging, undo skipping selection-only steps, one undo for the whole page (drawing, card and map edits in order, `pageUndo.ts`), wiring of the other areas | `Whiteboard.tsx`, `pageUndo.ts` |
| `pages/` | Pages, as in Excalidraw but bounded: the page is at least the window's size at 100% (no bars) and as big as what's on it; a smaller window keeps the zoom and shows part of the page, you pan to the rest, up to its edges (100% = one page unit per screen pixel). The edges are a wall during drags and resizes (`edgeWall.ts`); anything else past them is pulled back after (`keepInside.ts`). The bottom-right ‹ N / M › (its N / M opens tldraw’s page list), ←/→ keys | `camera.ts` (pure), `keepFilled.ts`, `edgeWall.ts`, `sheet.ts`, `PageArrows.tsx` |
| `style/` | The style panel (Excalidraw's, left under the menu) and the styles tldraw lacks, kept in a shape's `meta`: font sizes smaller than tldraw's, a background colour apart from the outline, exact (fixed dark and custom) colours the same in dark and light mode, with a custom picker and the last 5 custom colours (`ColorRow.tsx`); Crop in Actions for one picture | `StylePanel.tsx`, `styleMeta.ts` (pure), `colors.ts` (pure), `shapeUtils.ts` |
| `import/` | Bringing drawings in from elsewhere. `excalidraw/`: Excalidraw pastes, dropped .excalidraw files and the main menu's "Import Excalidraw file…", converted by our own code (not tldraw's) so position, size, rotation, exact colours, fonts and sizes, text wrapping, pictures with their crop, arrows with their bindings, frames and groups are kept; a notice lists what couldn't be converted exactly | `excalidraw/convert.ts` (pure), `excalidraw/importExcalidraw.ts`, `excalidraw/ImportNotice.tsx` |
| `lasso/` | Lasso selection: the tool, the loop overlay, the loop geometry | `LassoTool.ts`, `loop.ts` (pure) |
| `boards/` | Boardkit boards as whiteboard widgets (phase 2): the tldraw shape (scaled like a picture, its box follows the content), editing in place, a board with a linked Linkkit map shows its list, its map or both ("List \| Map \| Both", `views.ts`, `ViewSwitch.tsx`; the map from `maps/`), the toolbar's Board picker (an existing board, or "+ New board": a new Boardkit board, its name typed in place in `BoardName.tsx`; still empty, it leaves Boardkit with its widget: `emptyNewBoards.ts`). The board itself is drawn and edited by Boardkit's own code (npm dependency `boardkit`, its `src/app/whiteboard/`; every import goes through `boardkit.ts`) | `BoardShape.tsx`, `boardkit.ts`, `AddBoard.tsx`, `fit.ts` (pure) |
| `maps/` | Linkkit maps as whiteboard widgets (phase 3): the tldraw shape (`MapShape.tsx`, "linkkit-map": scaled like a picture, its box the part of Linkkit's page its boxes cover), editing in place (`MapView.tsx`), the toolbar's Map picker next to Board (an existing map, or "+ New map": a new Linkkit map, its name typed in place in `MapName.tsx`; still empty, it leaves Linkkit with its widget: `emptyNewMaps.ts`). A board with a linked map shows it too (boards/: List \| Map \| Both). The map itself is drawn and edited by Linkkit's own code (npm dependency `linkkit`, its `src/app/whiteboard/`; every import goes through `linkkit.ts`); Boardkit and Linkkit on one page hear each other's writes (`appsTogether.ts`) | `MapShape.tsx`, `linkkit.ts`, `AddMap.tsx`, `MapView.tsx` |
| `backup/` | The backup page at `/backup/`: one file with all of this site's browser storage (every localStorage key, every IndexedDB database: Boardkit's board background pictures, the whiteboard with its pictures), and a restore from it that first downloads what is there. Automatic backups of the same kind kept in the browser (on opening `/` or `/backup/`, every 10 min), within a storage budget, with a warning when one can't be kept. Each automatic backup also written to a folder picked on `/backup/` (banner with Reconnect on `/` when none is picked or permission is needed) | `BackupPage.tsx`, `format.ts` (pure), `storage.ts`, `auto.ts`, `policy.ts` (pure), `folder.ts`, `folderNames.ts` (pure) |

Later phases add `connections/`.

Pure files (`backup/format.ts`, `backup/policy.ts`, `backup/folderNames.ts`, `sheet.ts`, `camera.ts`, `loop.ts`, `styleMeta.ts`, `colors.ts`, `fit.ts`, `import/excalidraw/convert.ts`) have unit tests next to them
(`*.test.ts`, vitest). The e2e tests are in `../e2e/`.
